# secretserver.pro Fust assets

Public waifu images and hit sounds for the Fust Survival hub.

- `waifus/`: 12 PNG images
- `hitsounds/`: 50 MP3 and WAV files

Files can be downloaded from `https://raw.githubusercontent.com/GloryWasHere/secretserver-fust-assets/main/<path>`.

The current Fust script does not load these assets yet. This repository keeps them available for future waifu and hit sound controls.
